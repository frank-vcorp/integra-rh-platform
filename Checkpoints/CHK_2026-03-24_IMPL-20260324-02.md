## Riesgos Identificados

| Riesgo | Mitigación |
|--------|-----------|
| **Datos legacy con `ingresosArray`** | La inicialización lee ambas claves y prefiere `ingresos`; el save escribe solo `ingresos`. Registros que tenían `ingresosArray` deberán ser re-guardados por la analista para migrar. |
| **Campos `habitaDomicilio` boolean vs string** | El editor guarda como string "Sí"/"No"; el portal como boolean. La Vista genérica los renderiza correctamente en ambos casos. |
| **mapaCapturaUrl sin API key** | El encuestador solo genera la URL si `VITE_GOOGLE_MAPS_API_KEY` está configurado; si está vacío, el campo no existe y el panel simplemente no muestra la tarjeta (sin error). |
| **Chunk size >500KB** | Warning previo de Vite — no nuevo, no relacionado con estos cambios. |
