### 2. Adjuntos no-imagen — tarjeta Abrir/Descargar
- Nueva helper `isNonImageDataUrl(value)`: detecta `data:` URLs que **no** son imagen (regex negativo `/^data:(?!image\/)...;base64,/`).
- Nueva helper `mimeLabel(dataUrl)`: extrae etiqueta legible del mime type (p.ej. "PDF").
- Nuevo componente `AttachmentCard`: muestra nombre de campo + etiqueta mime + botones "Abrir" (ventana emergente con `<iframe>`) y "Descargar" (`<a download>`). Nunca imprime base64 crudo.
- `renderPrimitiveValue` recibe nuevo parámetro `label = ""` para pasarlo a `AttachmentCard`.
- Rama `isNonImageDataUrl` insertada **antes** de la rama `isUrl`, después de `isImageSrc`.
- Call site en `renderNode` actualizado para pasar `label` al tercer argumento.

## Riesgos residuales

1. **Retrocompatibilidad egresos**: capturas antiguas guardadas con claves `alimentacionDespensa`, etc. no se verán en los nuevos campos de egresos al editar. Los datos originales no se pierden (el merge solo sobreescribe lo editado), pero la analista necesitará re-introducir esos valores si los campos aparecen vacíos. La pestaña Vista siempre muestra el JSON completo como referencia.

2. **Comprobante como PDF**: improbable dado que el CameraField del encuestador solo acepta `image/*`, pero si existiera un registro antiguo con PDF base64 en un campo de foto, ahora se renderiza con AttachmentCard en lugar de texto crudo.

3. **Chunk size warning**: 2.19MB pre-existente, no generado por esta intervención.
