## Entregables Implementados

### 1. `server/utils/armadoHtmlRenderer.ts` (NUEVO — ~430 líneas)
- Renderer standalone que genera HTML editorial desde el snapshot inmutable
- CSS inline editorial completo (portada, TOC navegable con anclas, metric cards, footer legal)
- 8 constructores de secciones: `generales_candidato`, `documentos`, `investigacion_laboral`, `investigacion_legal`, `semanas_cotizadas`, `buro_credito`, `visita_domiciliaria`, `observaciones_conclusion`
- Logo Sinergia RH embebido como base64 (self-contained, funciona como Blob URL)
- TOC dinámico con `href="#anchor"` — solo incluye secciones seleccionadas
- XSS safety con función `esc()` para todos los datos del snapshot
- `loadLogoBase64()` lee el logo del filesystem del servidor

### 2. `server/routers/processes.ts` — Endpoint `getReportVersionHtml`
- `adminProcedure.use(requirePermission("procesos","view")).mutation(...)`
- Lee snapshot inmutable de DB por `versionId` — no accede a datos vivos
- Lanza `FORBIDDEN` si `ctx.user.role === "client"` (preview es solo interno)
- Llama `renderArmadoHtml(snapshot, sections, opts)` via import dinámico
- Retorna `{ html, versionNumber, status }` como `const`

### 3. `server/utils/estudiosocioPdf.ts` — Índice dinámico en PDF
- Añadido bloque visual "CONTENIDO DE ESTE REPORTE" post-calificación
- `PDF_INDEX_SECTION_LABELS`: mapa de 8 secciones a etiquetas display
- `PDF_SECTION_ORDER`: orden canónico de secciones
- Para cada sección incluida: dibuja `§ N` + nombre + línea de puntos punteada
- Sin hipervínculos internos (pdf-lib no soporta GoTo annotations en este flujo)

### 4. `client/src/pages/ProcesoDetalle.tsx` — Tab Armados rediseñada
- **Estado de armado actual** en CardHeader con badges `Sin armado` / `Borrador (vN)` / `Publicado (vN)` con fecha
- **Bloque de revisión de borrador** para el draft más reciente (Card ámbar con botones HTML + PDF + Publicar)
- **Botón "Vista previa HTML"** por cada versión en tabla desktop y tarjetas mobile
- **Confirmación de publicación**: `Dialog` con mensaje explicativo antes de ejecutar `publishReportVersion.mutate()`
- Checkboxes con `AlertTriangle` cuando no hay secciones seleccionadas
- `getVersionHtml = trpc.processes.getReportVersionHtml.useMutation()` — Blob URL en nueva pestaña con revoke a 60s

## Arquitectura de Flujo

```
Borrador generado (snapshot inmutable)
    │
    ├── Vista previa HTML → getReportVersionHtml (mutation) → renderArmadoHtml() → Blob URL
    │
    ├── PDF → generarArmadoClientePDF() → Firebase Storage → signedUrl
    │
    └── Publicar → confirmación Dialog → publishReportVersion() → status="published"
                                                                       │
                                                                       └── ClienteProcesoDetalle: solo ve published
```

---

## Restricciones de Diseño

- **Snapshot inmutable**: el preview HTML y el PDF derivan del mismo `snapshot JSON` frozen en DB — no leen datos vivos al abrir preview
- **HTML self-contained**: logo embebido como base64; funciona correctamente al abrir como Blob URL
- **PDF sin anclas clickeables**: el índice es visual (§N con líder de puntos) — pdf-lib requiere anotaciones PDFAnnotation para GoTo links internos
- **scope limitado**: el endpoint de preview es `adminProcedure` — clientes reciben `FORBIDDEN`
